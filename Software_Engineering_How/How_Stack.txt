STACK (Automatic Memory)
👉 What it is:

  A region of memory used for:
  
      function calls
      local variables
      return addresses
      saved registers

How it grows:
  The stack usually grows downwards (towards lower memory addresses).
    High Memory
      ↓
  +-----------+
  |   Stack   |
  +-----------+
    ↓ grows down

👉 Managed by:

CPU + compiler, not by you.

👉 Allocation:

Happens automatically when a function is called.

👉 Deallocation:

Happens automatically when a function returns.

👉 Fast?

YES — extremely fast, because it’s just a pointer move.

2. HEAP (Dynamic Memory)
What it is:

  A memory region used for dynamic allocation, where you manually allocate:

    malloc()
    calloc()
    realloc()
    new (in C++)

 How it grows:
  Heap grows upwards (towards higher addresses).

Low Memory
    ↑
+-----------+
|   Heap    |
+-----------+
    ↑ grows up

                                  ******************************  Stack Frame (Deep Understanding)   ****************************************

        Every time you call a function, a stack frame is created:
                          +----------------+
                          | Return Address |
                          +----------------+
                          | Saved Registers|
                          +----------------+
                          | Local Variables|
                          +----------------+
                          | Arguments      |
                          +----------------+

Stack is a fast, automatically managed memory region used for function calls and local variables. It grows downward and deallocates automatically when the function exits.

Heap is a dynamically managed memory region used for allocating memory at runtime using malloc() or new. It grows upward and is slower, because memory must be searched and manually freed.

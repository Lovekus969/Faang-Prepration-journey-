Bubble Sort
🔹 Idea:

Bubble Sort repeatedly compares adjacent elements and swaps them if they are in the wrong order.
It “bubbles” the largest element to the end after each pass.

🔹 Steps:
      Compare adjacent elements.
      Swap if the left is greater than the right.
      Repeat until the list is sorted.


| Case                  | Complexity      |
| --------------------- | --------------- |
| Best (already sorted) | O(n)            |
| Average               | O(n²)           |
| Worst                 | O(n²)           |
| Space                 | O(1) (in-place) |



What is an ADT (Abstract Data Type)?

An Abstract Data Type (ADT) defines what a data structure does, not how it does it.

➡️ In other words:

It specifies the behavior (operations) that can be performed on data.
It hides the implementation details of how those operations are carried out.

Abstract Data Type (ADT)

An Abstract Data Type (ADT) is a model of a data structure that defines

Formula for Number of Nodes in a Full Binary Tree

                  A full binary tree (also called a perfect binary tree) is one where:
                  Every level is completely filled.
                  Every non-leaf node has exactly two children.

🧮 Formula =======>>>           If the tree has L levels (counting root as level 1):

                              Total Nodes=2^L−1
